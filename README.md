# Streetwear Luxury Brand

Landing page desarrollada para una marca conceptual de moda urbana enfocada en diseño moderno, identidad visual y experiencia de usuario.

## Características

- Diseño responsive
- Interfaz moderna
- Optimización para dispositivos móviles
- Enfoque en branding digital

## Tecnologías

- HTML5
- CSS3
- JavaScript
- TypeScript
- Tailwind CSS

## Objetivo

Desarrollar una experiencia web atractiva para una marca de moda urbana utilizando buenas prácticas de diseño y desarrollo frontend.
